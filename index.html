Projects

Selected academic and practical work.

AquaGuard: Smart Plant Root Monitoring and Water Control

An ESP32 and IoT prototype that monitors plant root conditions and supports remote water-supply control. It uses Firebase Realtime Database and a Kodular app for data access and control.

ESP32IoTFirebaseKodular

Patient Monitoring System

An ESP32 prototype that combines sensor inputs for basic patient monitoring. It uses a DHT11 temperature and humidity sensor and a KY-039 pulse sensor, with an I²C interface in the setup.

ESP32DHT11KY-039I²C

DigSafe: Smart Transportation Monitoring

A GPS and weight-based truck monitoring project. The software prototype uses Python, Streamlit, Folium and an Isolation Forest model to flag potential overweight-vehicle events and show tracking information.

PythonStreamlitFoliumIsolation ForestGPS

Smart Object Detection and Alert System

A sensor-based prototype that uses an IR proximity sensor to detect nearby objects and trigger an alert. It explores basic sensing, input processing and alert mechanisms in an embedded application.
